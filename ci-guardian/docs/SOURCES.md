# Sources and provenance

This project's product scope is a new proposal. It is designed around the user's existing GitHub Actions PR checks and desire for reusable engineering standards.

Official external reference checked on 2 October 2026:

- [GitHub reusable workflows](https://docs.github.com/en/actions/how-tos/reuse-automations/reuse-workflows), for cross-package workflow boundaries.

All command names, report fields, generator ownership rules and milestones are toolkit design decisions. Before publishing generated workflows, recheck official GitHub documentation for current permissions, events, runner images and action revisions and run a provider pilot.
